# Workshop datasets

## Supervised learning

Training images:

```text
data/supervised/train/
├── Danaus_chrysippus/
├── Danaus_genutia/
├── Acraea_terpsicore/
└── Papilio_polytes/
```

Held-out known-species test images:

```text
data/supervised/test/known/
```

Unknown-species challenge:

```text
data/supervised/test/unknown/Eurema_hecabe/
```

Do **not** upload *Eurema hecabe* to Teachable Machine during training.

## Unsupervised learning

Flower images:

```text
data/unsupervised/flowers/
```

The filenames should not reveal biological species names.

The instructor may retain an answer key separately for the final reveal.

## Before class

Visually inspect every image before finalizing the repository. Remove images that are obviously misidentified, unusably small, dominated by unrelated subjects, or otherwise unsuitable for the teaching activity.
